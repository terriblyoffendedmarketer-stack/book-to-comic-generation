- Fewer panels per page (4-6 max, not 7-8) to give breathing room.
- Each panel should have clear visual foreground that isn't hidden by text.
- If a scene is dialogue-heavy, commit to it: bigger bubbles, simpler backgrounds, or split across more pages.

## Design Rules to Follow
1. Max 6 panels per page
2. Each panel's background should be at least 40% visible (not covered by text)
3. Dialogue should be 12-14px, not 11px
4. Full-width panels for atmospheric/establishing shots
5. Close-up face panels when emotion matters more than environment
6. When in doubt, add another page rather than cramming
